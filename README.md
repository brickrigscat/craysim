# Crayfish Simulator 🦞

Official website source for **Crayfish Simulator**, made by **Whyacat**.

**Website:** https://craysim.vercel.app

## About
Crayfish Simulator is an aquarium adventure built in PenguinMod. Play as Orange Cray, explore the aquarium, eat pellets, sleep in caves, complete quests, and work your way toward Day 100.

## Bug reports
Found a bug? Please open a [GitHub Issue](https://github.com/brickrigscat/craysim/issues/new) with:
- What happened
- What you expected to happen
- Steps to reproduce the problem
- A screenshot, if helpful

A GitHub Action automatically replies to new issues to confirm that the report is on the bug list. **An acknowledgement is not a promise that the bug has already been fixed.**

## Website
This repository contains the public website source. The PenguinMod game itself is developed separately.
